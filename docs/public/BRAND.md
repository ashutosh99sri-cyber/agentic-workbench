# WOOKhoop brand implementation

The repository owner confirmed WOOKhoop as the presentation brand for Agentic Workbench. No formal logo pack or brand guidelines were supplied. The public WOOKhoop website was inspected on 15 October 2026; the exact observations and source URLs are in [brand provenance](brand-provenance.json).

| Role | Observed website value |
| --- | --- |
| Brand blue | `#1854c2` |
| Ink | `#0b0f14` |
| Paper | `#f1f3f4` |
| Soft blue | `#dde7f8` |
| Border | `#d2d8de` |

The circular icon is retained from the verified website asset. The README banner and technical diagrams were created for this repository using the observed palette. Website fonts were not redistributed: the PDF uses Helvetica/Courier, and SVGs request system sans-serif fonts. These are practical substitutions, not a claim that a formal typography standard was supplied.

Use **WOOKhoop Agentic Workbench** in presentation copy. Keep the established technical identifiers in commands and code. Do not imply official affiliation with tool vendors, add invented screenshots or display remote CI/star/download badges without real targets.

The static [status strip](assets/status-badges.svg) labels declared requirements and maturity; it does not claim passing hosted CI. The [banner](assets/wookhoop-banner.svg), [architecture](assets/architecture.svg), [repair](assets/repair.svg) and [authority](assets/authority.svg) have editable SVG sources. Mermaid diagram sources are supplied beside this file.
